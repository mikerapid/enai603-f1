- `fastf1_cache/`: Local cache of raw F1 session data downloaded from the FastF1 live-timing API. The notebook reads from this cache automatically. If missing, it will be regenerated on first run.

## Reproducing the data

All data comes from the [FastF1 Python library](https://docs.fastf1.dev/).

### Setup

```bash
pip install -r requirements.txt
brew install libomp   # macOS only — required by xgboost
```

### Fetching the data

```bash
jupyter notebook f1_tyre.ipynb
```

The notebook will read from the `fastf1_cache/` directory if it already has the data files, or download the data from the F1 live-timing servers if they're missing.

The notebook pulls both full F1 seasons (2024 and 2025) — 48 race sessions covering 24 unique circuits.
